# 微信小程序上架 · 一步步操作指南

> 本项目已改造成**真正的微信原生小程序工程**（位于 `miniprogram/` 目录），不再是网页 demo。
> 本指南带你从 0 把它上架到微信。按步骤走，遇到卡点再看「常见被拒 / 避坑」一节。

---

## ⭐ 首选方案：走微信内网链路（免域名、免备案）

> **2026-09 更新**：小程序调云托管服务，推荐用 `wx.cloud.callContainer`（微信私有链路）。
> **不需要配置 request 合法域名，也不需要域名 ICP 备案。**
>
> 为什么重要：云托管的**默认公网域名**（`*.run.tcloudbase.com`）微信官方明确写了
> 「默认公网域名性能有限制……小程序后台也无法配置使用默认公网域名」——
> 所以老方案（`wx.request` + 默认域名）在体验版/正式版/朋友扫码时**必然 request:fail**。
>
> 本项目 `miniprogram/` 已经改好了，你只需三步：
> 1. 后端部署到云托管（用 `server/` 的 `Dockerfile`），服务状态 = 运行中；
> 2. 小程序后台「设置 → 功能设置 → 基础库最低版本」设为 **2.23.0 及以上**；
> 3. 核对 `miniprogram/app.js` 里的 `cloudEnv`（环境 ID）和 `cloudService`（服务名）与控制台一致。
>
> `app.js` 里 `useContainer: true` 走内网链路；改成 `false` 则退回公网 `wx.request`（仅开发者工具/真机调试可用）。
>
> 👇 下面的「买域名 + ICP 备案」章节，仅在你需要**公网直连**（网页端 demo、其他平台调用）时才需要。

---

## 〇、准备工作（先确认这几样）

| 项目 | 说明 |
|------|------|
| 微信账号 | 一个微信号（建议用你常登录的那个） |
| 主体资质 | **个人**主体即可上架「工具/旅游攻略」类；若要在线卖旅游产品需**企业/个体工商户**+ 旅行社资质 |
| 后端服务 | 你的 FastAPI 后端（`server/`）部署到**云托管**（走内网链路方案时，无需备案域名） |
| 域名 | **走内网链路则不需要**；只有公网直连才需要已 ICP 备案的 HTTPS 域名 |
| 电脑 | 装好「微信开发者工具」（官网下载 Windows/macOS 版） |

> ⚠️ 关键点：小程序**不能**连 `localhost`、不能连 `http`。走 `callContainer` 内网链路可绕开域名与备案要求。

## 第 1 步：注册并认证小程序

1. 打开 https://mp.weixin.qq.com → 右上角「立即注册」→ 选「小程序」。
2. 用邮箱注册（一个邮箱只能注册一个小程序），激活邮箱。
3. 登录后，在「设置 → 基本设置」里填**名称、头像、简介**。
4. **认证**（可选但推荐）：个人主体做「个人」认证免费；企业认证 300 元/年。认证后可用更多能力、审核更快。
   - 学生 demo / 毕业设计：先选**个人主体**即可，类目选「工具-查询」或「旅游-旅游攻略」，通常不需要旅行社资质。

完成后，在「开发管理 → 开发设置」里能看到你的 **AppID（小程序 ID）**，复制下来。

---

## 第 2 步：把 AppID 填进工程

打开 `miniprogram/project.config.json`，把 `"appid": "touristappid"` 改成你自己的 AppID：

```json
{
  "appid": "wx你的真实AppID",
  ...
}
```

> 开发阶段用 `touristappid`（游客模式）也能编译预览，但**真机预览和提交审核必须用你自己的 AppID**。

---

## 第 3 步：部署后端（选一种）

后端是 Python + FastAPI，必须 7×24 在线。三种方案：

### 方案 A：微信云托管（最省心，推荐）
- 入口：小程序后台「云开发 → 云托管」或 https://cloudbase.net
- 把项目做成 Docker 镜像（下面给 Dockerfile），推到云托管，它自动给一个 `https://xxx.ap-shanghai.run.tcloudbase.com` 的域名。
- **仍需一个备案域名做自定义域名**（云托管默认域名有时可直接用于 request 白名单，但正式上架建议绑定自己备案域名）。

### 方案 B：腾讯云 / 阿里云轻量服务器（最通用）
- 买一台轻量应用服务器（2 核 2G 约 ¥60–100/年够用）。
- 域名在云厂商处**ICP 备案**（约 3–20 个工作日，免费但耗时，尽早办）。
- 服务器上用 `uvicorn` 或 `gunicorn` 起服务，前面用 **Nginx/Caddy** 做 HTTPS 反代。

### 方案 C：微信云开发云函数（改动大，不推荐）
- 要把 FastAPI 改成云函数入口，适配成本高，Pass。

**最小 Dockerfile（放 `server/` 目录）：**
```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
EXPOSE 8000
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

**服务器上用 gunicorn 起（备选）：**
```bash
pip install gunicorn
gunicorn -k uvicorn.workers.UvicornWorker -w 2 -b 0.0.0.0:8000 main:app
```

> 部署后务必验证：浏览器/Postman 访问 `https://你的域名/health`，应返回 `{"status":"ok",...}`。

---

## 第 4 步：配置服务器域名白名单（关键！）

1. 小程序后台 → 「开发管理 → 开发设置 → 服务器域名」。
2. 在 **request 合法域名** 里添加你的后端域名，例如：
   ```
   https://your-domain.example.com
   ```
3. 保存（需要域名已备案 + 支持 HTTPS，且证书有效）。
4. **不需要** 配 downloadFile / uploadFile（我们没用图片上传下载，天气也是后端代理）。

> 没配白名单 → 真机上 `wx.request` 直接报 `url not in domain list`，所有接口调不通。

---

## 第 5 步：改小程序里的后端地址

打开 `miniprogram/app.js`，把 `apiBase` 改成你的真实域名：

```js
globalData: {
  apiBase: "https://your-domain.example.com"   // ← 改成你备案的 HTTPS 域名
}
```

> 开发阶段想直连本地后端：`apiBase` 填 `http://你电脑局域网IP:8000`，并在开发者工具里勾「详情 → 本地设置 → 不校验合法域名、TLS 版本以及 HTTPS 证书」，即可真机临时调试。

---

## 第 6 步：用微信开发者工具导入并预览

1. 打开「微信开发者工具」→ 扫码登录（用第 1 步的微信号）。
2. 「导入项目」→ 目录选 `miniprogram/` → 填 AppID → 导入。
3. 工具会自动编译，左侧模拟器能看到三屏界面（首页 / 加载 / 结果）。
4. 点顶部「编译」若有报错，看控制台红字修（一般都是 WXML 语法或路径问题）。

---

## 第 7 步：真机预览

1. 点工具栏「预览」→ 生成二维码 → 手机微信扫码。
2. 手机上填目的地、天数，点「开始规划我的行程」：
   - 若后端是 **mock 模式**（没配 DeepSeek Key）→ 秒回示例行程，演示流畅。
   - 若配了真实 Key → 走「提交 + 轮询」，约 1–3 分钟出真实 AI 行程（小程序每 3 秒问一次，不会超时）。
3. 天气条会显示每日真实天气（来自 Open-Meteo，经后端代理）。

---

## 第 8 步：提交审核 + 发布

1. 开发者工具点「上传」→ 填版本号（如 `1.0.0`）和备注 → 上传成功。
2. 小程序后台 → 「管理 → 版本管理 → 开发版本」→ 点「提交审核」。
3. 填写：
   - **类目**：个人选「工具-查询」或「旅游-旅游攻略」。
   - **功能页面**：填首页路径 `pages/index/index`。
   - **隐私协议**：在「设置 → 服务内容声明 / 用户隐私保护指引」里配置（本小程序不收集敏感信息，声明「仅使用用户输入的行程偏好文本」即可）。
   - **截图**：传几张模拟器/真机界面截图（首页、结果页）。
4. 提交后等审核（通常 1–7 天，首次可能稍慢）。
5. 审核通过后点「发布」→ 正式上线，搜索小程序名即可找到。

## 常见被拒 / 避坑清单

- ❌ **域名没备案 / 没配白名单** → `url not in domain list`。先第 3、4 步再做真机。
- ❌ **用了 http / localhost** → 小程序一律拒绝，必须 HTTPS + 白名单。
- ❌ **类目选错**（如个人主体选「旅游-旅行社」）→ 需企业资质，会被拒。学生 demo 选「工具」或「旅游攻略」类。
- ❌ **隐私协议缺失 / 实际收集未声明的信息** → 在后台补齐《隐私保护指引》。
- ❌ **内容涉违规**（政治、色情、诱导分享等）→ 本 demo 是中性旅游内容，正常。
- ⚠️ **审核期间后端必须在线** → 审核员会真机点你的小程序，后端挂了会判「功能不可用」。
- ⚠️ **首屏加载慢** → 我们已用 mock/异步轮询避免卡死，但真实模式 1–3 分钟属正常，加载页有动画说明。

## 后端接口（小程序依赖的）

| 接口 | 方法 | 用途 |
|------|------|------|
| `/api/plan/async` | POST | 提交行程任务，立即返回 `{task_id}` |
| `/api/plan/async/{task_id}` | GET | 轮询状态：`pending/running/done/failed` |
| `/api/weather` | GET | 真实天气（Open-Meteo 代理，单域名） |
| `/api/plan` | POST | 同步版（网页 demo 用，小程序也可直接用但受 60s 限制） |

> 小程序走「异步提交 + 轮询」是为了绕开 `wx.request` 60 秒超时——真实 AI 行程要 100+ 秒，直接同步调用会超时失败。
